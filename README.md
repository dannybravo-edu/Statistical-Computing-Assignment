
# Statistical Computing Assignment

## 1. Introduction
This project demonstrates basic statistical computing
using Python and a sample student dataset.

## 2. Objectives
- Practice basic statistical analysis.
- Calculate descriptive statistics.
- Learn Git version control.
- Upload and share a project using GitHub.

## 3. Project Files
- `sample_data.csv`: Contains sample student data.
- `analysis.py`: Performs descriptive statistical analysis.
- `README.md`: Describes the project and its contents.

## 4. Dataset Variables
- Student_ID: Student identification number.
- Age: Student age in years.
- Study_Hours: Hours spent studying.
- Statistics_Score: Examination score out of 100.

## 5. Statistical Methods
The Python script calculates:
- Mean
- Median
- Standard deviation
- Minimum and maximum values

## 6. Tools Used
- Python
- Visual Studio Code
- Git
- GitHub

## 7. How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python analysis.py`.

## 8. Conclusion
This project demonstrates the use of Python for
descriptive statistics and Git for tracking project changes.
